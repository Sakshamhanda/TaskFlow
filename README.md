# 📋 TaskFlow — Interactive Kanban Board

A clean, responsive, and interactive Kanban-style task management web application built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

---

## ✨ Features

- ➕ **Task Creation:** Quickly add tasks directly into the To-Do column.
- 🎯 **HTML5 Drag & Drop:** Seamlessly drag tasks across columns (**To-Do**, **In-Progress**, **Completed**).
- 🗑️ **Task Deletion:** Remove completed or unwanted tasks with a single click.
- 💾 **Local Storage Persistence:** Tasks stay saved in the browser even after refreshing the page or closing the browser.
- 📱 **Responsive Design:** Flexbox-based layout that adapts smoothly to both desktop and mobile screens.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and native Drag and Drop API (`draggable="true"`).
- **CSS3:** Flexbox layout, custom styling, hover states, and responsive media queries.
- **JavaScript:** DOM manipulation, event listeners (`dragstart`, `dragover`, `drop`), and Web Storage API (`localStorage`).

## 💻 Getting Started Locally

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Sakshamhanda/TaskFlow.git
   ```

2. **Navigate to the directory:**

   ```bash
   cd TaskFlow
   ```

3. **Open the project:**
   Simply open `index.html` in your favorite web browser:

   ```bash
   # On Linux / Mac
   xdg-open index.html
   ```
